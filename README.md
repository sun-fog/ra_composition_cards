# Карточки (React + Bootstrap 5)

Учебный проект: реализация компонента карточек в стиле Bootstrap 5 с использованием React.

Разметка и стили повторяют [официальный компонент Card из Bootstrap 5](https://getbootstrap.com/docs/5.3/components/card/).

## Как запустить

```bash
npm install
npm run dev
